### 0. エグゼクティブサマリー

- 今回の結論: v2.0 リリースに向けた製品リブランディングを実施。「業務文脈の強化」を主軸に、`useCase` / `codeExample` / `confusables` を持つ**解説ペイン**と、**類語識別モード（β）**を追加した。データ拡張は Wave 1 (32 語) のみ。残り約 640 語の解説執筆は Wave 2 / 3 で継続。

  - 全コードを IIFE で隔離、`validateDataset()` 起動時警告、`window.MustDevEigo` 名前空間公開
- 未完: 解説カバレッジ Wave 2 / 3、類語識別モードの UX 評価、既存 642 語の精査タスク
- 次回の狙い: 利用者からのフィードバックを反映した上で Wave 2 (約 60 語追加) に着手し、解説カバレッジを 50% へ引き上げる。

#### Issue: 20260502-02

- 状態: 新規
- 分類: アクセシビリティ / 制約環境
- タイトル: Web Speech API 非対応環境での代替手段がない
- 種別: 事実
- 要約: 発音機能 (キー「5」) は `speechSynthesis` 依存。Safari の古いバージョン、Linux Firefox 一部環境では動作しない。代替の音声ファイル提供や明示的な無効化通知がない。
- 証拠: `MustDevEigo.html` の `ttsAvailable = "speechSynthesis" in window`。非対応時は発音ボタンが無効化されるのみ。
- 内容: 利用者は「ボタンが押せない」と気づかないまま離脱する可能性がある。
- ユーザー影響: 小。発音は補助機能で必須ではない。
- 緊急度: 低
- 実装コスト: 中（音素資産を持つ前提。あるいは案内の追加のみで対処可）
- 確信度: 高
- 次の行動: 短期的には TRAINING_GUIDE.md / README.md で対応ブラウザを明示。中期的には Web Speech 非対応時に発音ボタンを完全非表示にし、英文発音の参考リンクを併記する案を検討。

#### Issue: 20260502-04

- 状態: 新規
- 分類: スケーラビリティ / 配布性
- タイトル: 単一 HTML 200KB 超過時の配布性が課題化する可能性
- 種別: 推論
- 要約: v2.0 時点で約 145KB / 3,800 行。Wave 3 完了で +60〜80KB → 約 220KB に到達する見込み。リポジトリ内の他ツール（180KB 程度まで）と同水準で許容範囲だが、それを超えると初回ロードと diff レビューに影響が出始める。
- 証拠: 既存 `スケジュール作成ツール.html` 180KB、`マニュアル.html` 151KB と比較。Wave 1 で +約 20KB（解説 32 語分）増加した実績から線形外挿。
- 内容: 解説テキストはミニファイせず diff レビューしやすさを優先しているため、ファイルサイズはほぼリニアに増える。
- ユーザー影響: 小。単一 HTML として配布する限り問題化しない見込み。
- 緊急度: 低
- 実装コスト: 大（外部 .json 化は CLAUDE.md の単一 HTML 原則と齟齬する。検討時にはポリシー再考が必要）
- 確信度: 中
- 次の行動: Wave 3 完了後にサイズ実測。200KB を超えたタイミングで「単一 HTML ポリシーの再検討 Issue」を立てる。短期的には軽減策なし。

#### Issue: 20260502-05

- 状態: 新規
- 分類: 保守性
- タイトル: confusables の双方向リンクが手作業
- 種別: 事実
- 要約: A → B / B → A の双方向リンクは手で書く必要がある。`validateDataset()` で参照切れは検出されるが、双方向性の欠落は警告されない。
- 証拠: `MustDevEigo.html` の `validateDataset()` は `allWords.has(c.word)` だけを確認。
- 内容: 片方向リンクが偶発的に発生し得る（A は B を類語として登録、しかし B には A を登録し忘れる）。
- ユーザー影響: 小。学習効果は片方向でも得られる。ただし類語識別モードで非対称な挙動が起きる可能性。
- 緊急度: 低
- 実装コスト: 小（`validateDataset()` への双方向チェック追加）
- 確信度: 高
- 次の行動: Wave 2 着手前に `validateDataset()` を拡張し、「A→B はあるが B→A がない」ケースを警告化する。
