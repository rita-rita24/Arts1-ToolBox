# TRAINING_GUIDE — 研修担当者向け運用ガイド

`MustDevEigo` を新卒・ジュニアエンジニアの研修コンテンツとして利用するための導入手順・推奨カリキュラム・運用上の注意をまとめたガイドです。

## 1. このツールが解く課題

新卒・ジュニアが業務で詰まりやすい場面：

- **英語ドキュメントが読めない**: API リファレンス・公式ドキュメント・GitHub Issue が英語の壁で読み進められない。
- **コードレビューで使うべき語が出てこない**: `parameter` と `argument`、`property` と `attribute` の使い分けが曖昧で、レビューコメントが不正確になる。
- **略語の正式名称を知らない**: `attr`・`param`・`prop` が何の略か即答できず、命名規則が場当たり的になる。
- **ドキュメント探しのキーワードが分からない**: `deprecated` を「非推奨」と訳せないので、リリースノートを読み飛ばす。

汎用的な英単語アプリでは「業務で使う場面」と「混同しやすい類似語」をカバーしないため、上記の壁を解消できません。`MustDevEigo` は **意味 + 使用シーン + コード例 + 類語比較** をワンセットで提供することで、「明日のレビューで使える」ことを目指しています。

## 2. 想定対象

- 新卒エンジニア（プログラミング学習 1〜6 ヶ月）
- ジュニアエンジニア（実務経験 0〜2 年）
- 文系出身で IT 用語に不慣れなメンバー
- 海外オフショアとのコミュニケーションを担当することになった中堅

## 3. 研修導入手順

### 3.1 配布

1. リポジトリから `MustDevEigo.html` 1 ファイルを取得し、社内ファイル共有 / 社内 GitHub に配置。
2. 受講者にファイルパスを共有。受講者は**ファイルをダブルクリックしてブラウザで開く**だけで起動できる（インストール / アカウント不要）。

### 3.2 初回セットアップ

1. ブラウザで開くと「ようこそ」モーダルが表示される。**お名前**を入力（30 字以内、後から変更可能）。
2. ホーム画面に遷移し、「演習を始める →」で初回演習に入る。
3. 推奨ブラウザ: **Google Chrome / Microsoft Edge の最新版**。Firefox・Safari でも動作するが Web Speech API（発音）の対応状況が異なる。

### 3.3 動作確認チェックリスト（受講者）

- [ ] ホーム画面が表示された
- [ ] 「ようこそ」モーダルでお名前を入力できた
- [ ] 「演習を始める」で 1 問解答できた
- [ ] 解答後に「使用シーン」など解説ペインが表示される問題があった（Wave 1 の 32 語）
- [ ] ダークモード切替が動いた
- [ ] 単語帳画面の行をタップして展開できた

## 4. 推奨カリキュラム例

総時間目安: 約 3 時間（5 日間に分散推奨）

| Day | 分野 | 出題数 | 時間 | 達成目標 |
|---|---|---|---|---|
| Day 1 | prereq（前提） | 全 83 問 | 30〜40 分 | 入門語彙の把握。正答率 60% 超 |
| Day 2 | basic（ベーシック） 50 問 × 1 セッション | 30 分 | 30 分 | 頻出語に慣れる |
| Day 3 | basic 50 問 × 2 セッション | 60 分 | 60 分 | basic 全体で正答率 70% 超 |
| Day 4 | abbr 30 問 + acronym 30 問 | 40 分 | 40 分 | 略語・頭字語の正式名称を覚える |
| Day 5 | 苦手復習 + 単語帳で解説熟読 | 30 分 | 30 分 | 苦手語ゼロを目指す。解説あり 32 語の使い分けを覚える |

ペア学習にする場合: Day 2〜4 で受講者 2 人組を作り、解答後に「他の選択肢の意味も説明する」ルールにすると定着率が上がります。

## 5. 想定到達点（KPI 例）

研修担当者が成果を測る指標：

- **全カテゴリの正答率 80% 以上**: 履歴の直近 5 件平均で確認。Day 5 完了時点での目標。
- **苦手語ゼロ**: ホーム画面の「苦手復習」CTA が消えている状態。
- **解説あり語の理解**: Wave 1 の 32 語について「使い分け文」を口頭で説明できる。

## 6. ピットフォール

研修現場でよく起こる問題と対処：

- **受講者が「全問」で始めて集中切れ**: 推奨は 30 問。全 674 語を一度に出すと 1 セッション 60 分超になり集中力が持たない。
- **Web Speech API 非対応で発音できない**: Safari の古いバージョン、一部 Linux Firefox では動作しない。発音は補助機能なので学習継続には支障なし。事前に「動かないブラウザもある」とアナウンスすると親切。
- **プライベートブラウジングで履歴が消える**: IndexedDB が無効化されるため起動はできるが履歴・苦手記録が保存されない。**通常モードのブラウザを使うよう案内**。
- **14 日 TTL で履歴消失と感じるケース**: 14 日間アプリを開かないと履歴・苦手・選択設定が自動破棄される（ユーザー名のみ保持）。「定期的に開かないとリセットされる」を事前案内。
- **解説ペインがある問題と無い問題の体験差**: Wave 1 の 32 語のみ解説あり。残りは短文フィードバックのみ。「v2.x で順次追加予定」と説明する。

## 7. 質問が出やすい単語 Top10 と回答テンプレ

研修中に受講者から質問が来やすい混同ペア：

1. **parameter vs argument**: 「parameter は受け取り側（定義）、argument は渡し側（呼び出し）」。コード例で対比すると即理解。
2. **attribute vs property**: 「HTML 要素には attribute、JS オブジェクトには property」と覚える。React の props は property の略。
3. **method vs function**: 「method は何かに属する function」。クラスや組み込みオブジェクトにくっついたら method。
4. **constant vs default**: 「constant は再代入できない値、default は省略時に使われる値」。重なる場面はあるが概念は別。
5. **API vs SDK**: 「API は機能の入り口、SDK はそれを使いやすくしたキット」。AWS SDK は AWS API のラッパー。
6. **URL vs HTTP**: 「URL は住所、HTTP はその住所と話すお作法」。URL だけでは通信できない。
7. **dependency vs module**: 「module はコードの単位、dependency は module 間の依存関係」。
8. **deprecated**: 「非推奨」。動くが将来削除予定。リリースノートで頻出。
9. **environment vs configuration**: 「environment は実行環境（dev / prod）、configuration はそこに入れる設定値」。
10. **arg / param / attr / prop / val**: 略語は元の単語を必ず確認させる。コードレビューで「prop ってどっち？」とよく聞かれる。

## 8. 研修後フィードバックフォーム例

下記の項目で受講者にアンケートをとると改善サイクルを回しやすい：

```
1. 各カテゴリの正答率（Day 5 終了時点）
   - prereq: ___%   basic: ___%   advanced: ___%
   - abbr:   ___%   acronym: ___%

2. 解説ペイン (Wave 1 の 32 語) の役立ち度（5 段階）
   1: 全く役に立たない → 5: 非常に役に立った
   評価: ___

3. 「明日のレビューで使えそう」と思った語を 3 つ挙げてください。
   1) ___    2) ___    3) ___

4. 解説ペインで追加して欲しい情報があれば教えてください。
   - [ ] よくある誤訳例
   - [ ] 関連する社内ドキュメント / Slack チャンネル
   - [ ] 発音記号
   - [ ] その他: ___

5. 操作で困った点があれば教えてください。

6. 解説を追加して欲しい単語があれば 5 つまで挙げてください。
```

回収結果は次の Wave で「優先解説対象語」を決める判断材料に活用します。

## 9. 研修担当者向け運用 Tips

- 配布前に最新版を取得し、ローカルでひと通り動作確認すること（Chrome 推奨）。
- 受講者の進捗確認は「履歴を HTML で保存」で各自に提出してもらうのが手軽。
- グループ研修の場合、Day 5 に「最も覚えにくかった語」をひとりずつ共有する 5 分間を設けると定着率が高まる。
- IndexedDB / 14 日 TTL の挙動は受講者にとって直感的でないため、初回案内で必ず触れる。
