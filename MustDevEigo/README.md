# MustDevEigo

`MustDevEigo.html` は、エンジニア必須英単語（前提・基本・略語・頭字語など全 5 カテゴリ・約 670 語）を 4 択クイズで学習できるローカル完結型のシングル HTML ツールです。v2.0 では「明日のレビューで使える」ことを訴求軸に、`useCase`・`codeExample`・`confusables` を備えた**解説ペイン**を追加しました。

## 起動方法

1. `MustDevEigo.html` をブラウザで開きます。
2. インストールやビルドは不要です。インターネット接続は Google Fonts の取得時のみ使用します（オフラインでも問題なく動作します）。

## 主な機能

- **演習（4 択クイズ）**: 分野別 / 出題数 / シャッフル設定
- **解説ペイン（v2.0）**: 解答後に「使用シーン」「コード例」「混同しやすい類語」を表示
- **コード例のシンタックスハイライト**: 自前実装で 7 言語対応 (js / ts / py / java / go / rb / sh / sql / html)、コピーボタン付き
- **単語帳**: カテゴリ・検索フィルタ、行展開で解説ペインを表示、「解説あり N 語」バッジ
- **苦手復習**: 直近で間違えた語だけを抽出して再演習
- **結果画面**: セッション正答率・振り返りリスト・各語に「解説」モーダルへのリンク
- **エクスポート**: 1 セッションの結果と全履歴を HTML / CSV で書き出し
- **ダークモード**: ヘッダーから切り替え、CSS トークンで全画面追従
- **ユーザー名**: 結果出力に使う名前（30 字以内）。14 日活動なしで自動破棄
- **キーボードショートカット**: 1〜4 で選択 / 5 で発音 / Enter で次へ / Esc で通知閉じ

## v2.0 で追加された解説ペイン

解答直後の `#feedback` 直下に表示されます。データを持たない語ではペイン自体を出さず、現行の短文フィードバックのみ表示します（フォールバック）。

- **使用シーン**: 80 字以内の文。意味の混同を防ぐ「使い分け」が一文必ず入ります。
- **コード例**: コピペ実行可能な 30 行以内のスニペット。言語バッジとコピーボタン付き。
- **混同しやすい類語**: タップで意味をトースト表示、「単語帳で見る」で詳細へ遷移。

Wave 1 (v2.0 同梱) では 32 語に解説を備えています。Wave 2 / 3 で順次拡充予定です（[REPORT.md](REPORT.md)）。

## キーボードショートカット

| キー | 効果 |
|---|---|
| 1〜4 | 選択肢を選ぶ |
| 5 | 出題中の単語を発音 |
| Enter | 解答後に次の問題へ進む |
| Esc | 通知 / 解説モーダルを閉じる |

## 保存仕様

- **保存先**: IndexedDB データベース `MustDevEigo` (v2)、ストア `kv`
- **保存キー**:
  - `theme`: ライト / ダーク選択
  - `history`: 直近 30 件のセッション履歴
  - `selection`: 直近の出題分野・問題数・シャッフル設定
  - `wordStats`: 単語ごとの正誤履歴（苦手復習で利用）
  - `userName`: 結果出力に使うユーザー名
  - `lastActivityAt`: 最終アクティビティのタイムスタンプ
  - `appSchemaVersion`: 2 (v2.0 で追加された版マーカー)
- **TTL**: `lastActivityAt` から 14 日を超えたデータは起動時に自動破棄。ユーザー名のみ保持。
- **マイグレーション**: 旧 v1 ユーザーは履歴・苦手・ユーザー名すべて引き継がれます（実体スキーマ未変更）。
- **localStorage 互換**: 旧キー `codeeigodojo_state_v1` がある場合は初回起動時に IndexedDB へ移行します。

## 既知の制約

- **Web Speech API**: 発音機能はブラウザ依存。Safari / 古い Firefox では動作しないことがあります。
- **シンタックスハイライト**: 自前実装で 7 言語対応 (js / ts / py / java / go / rb / sh / sql / html)。それ以外は等幅プレーン表示にフォールバック。
- **IndexedDB が無効化されている環境**（プライベートブラウジング等）では履歴が保存されません。動作自体は継続します。
- **単一 HTML ファイル**: ビルドプロセス不要。CLAUDE.md の方針に従い、外部 CDN への依存は Google Fonts のみ。
