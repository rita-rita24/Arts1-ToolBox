# TextChanger

1行ごとの入力値を、5種類の形式へ同時変換する単体HTMLツールです。

## 業務UI版

- `TextChanger.html` に業務UIのスタイルを適用しています。
- 提供された GYOMU-UI 0.6.1 の配色・文字サイズ・操作部品の寸法を使用しています。既存の文言・ボタン数・5種類の変換機能は維持しています。
- コピーボタンは主要ボタン用の青系配色を使用します（ライトは青、ダークは淡い青）。
- コピー対象が空のボタンは無効になり、ホバー時は操作禁止のカーソルを表示します。変換結果が生成されると再び操作できます。
- 連番調整の増減値は左寄せで表示し、入力幅と上下ボタンの手前の余白を確保しています。
- ライト/ダーク切り替えは、ヘッダー右上の太陽／月アイコンで操作します。
- 初回表示はライトモードです。保存済みのテーマ設定がある場合は、その設定を優先します。
- CSSはHTML内の `<style>`、JavaScriptは `<script>`、アイコンはインラインSVGとして内包しています。別のCSS・JS・フォントファイルは不要で、`TextChanger.html` 1ファイルだけをコピーしてオフラインで利用できます。
- 狭い画面では1列に並び、タッチ環境の操作領域は44pxを確保します。
- 入力内容・テーマなどの保存キーは従来と同じです。ファイルを直接開いた場合の保存範囲はブラウザに依存します。

## できること

- 画面を左右1:2で表示（両端に少し余白あり）
  - 左: 入力欄のみ
  - 右: 変換結果カード5種を縦に表示
- 入力に応じて、5モードを同時リアルタイム変換
  - A5M2用 Caption 変換
  - タブ区切り変換（Excel向け）
  - SQL の IN 句変換
  - PostgreSQL `SELECT + INSERT + DELETE` 変換
  - 連番調整（テキスト中の数値を一括で増減）
- 各カード右上の「コピー」ボタンで、そのカード結果だけをコピー
- ライト/ダークモードをヘッダー右上のスイッチで切り替え
- 入力内容とテーマ設定を `localStorage` に保存

## 使い方

1. `TextChanger.html` をブラウザで開きます。
2. 左の入力欄に、1行に1つずつ値を入力します。
3. 右側5カードに同時表示された結果を確認します。
4. 必要な形式のカード右上「コピー」を押して利用します。

PostgreSQL `SELECT + INSERT + DELETE` カードの使い方:
- 1行目をカラム名（ヘッダー）、2行目以降をデータ行にしたタブ区切り表を貼り付けます（Excelのコピー貼り付けを想定）。
- コピーボタン左のテーブル名入力で、生成先テーブルを変更できます（初期値は空欄）。
- テーブル名入力を変更すると、生成結果に即時反映されます。
- テーブル名入力が空欄の場合は、`???` で生成します。
- `SELECT` / `DELETE` の `WHERE` 条件では、空欄セル・`NULL` 文字列（大文字小文字無視）・`<< NULL >>`・`< NULL >`・`« NULL »` を条件に含めません（全行で条件が空になる場合は `WHERE 1 = 0` になります）。
- `INSERT` では、`NULL` 文字列（大文字小文字無視）・`<< NULL >>`・`< NULL >`・`« NULL »` は `NULL` として扱い、空欄セルは半角スペース1文字（`' '`）として出力します。
- 事前チェック用の `SELECT` 文を冒頭に出力します（各行の `DELETE` と同じ条件で `SELECT * FROM ...`）。
- `INSERT` と `DELETE` はそれぞれ `BEGIN;` / `COMMIT;` で囲んで生成します。
- `SELECT` / `INSERT` / `DELETE` の文末セミコロンは、単独行（左端）で出力します。

連番調整カードの使い方:
- コピーボタン左の増減値入力に整数を入れると、入力テキスト中のすべての数字に対して足し算（負数なら引き算）した結果が出力されます。
- 入力の改行や空行はそのまま保持されます。例えば `No.1` → `No.2` → `No.3` のような連番テキストに対して `5` を入れると `No.6` → `No.7` → `No.8` になります。
- 増減値が空欄または `0` の場合は、入力テキストをそのまま出力します。

## 補足

- 外部送信は行わず、変換処理はブラウザ内で完結します。
